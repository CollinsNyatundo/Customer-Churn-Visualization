## [Unreleased]

### Fixed — Code review round 3 (line-by-line source inspection)
- **`api/explain.py` completely broken**: hard-coded pipeline step name
  `"preprocessor"` never matched the real `"pre"` used by every algorithm
  in `algorithms.py` — every `/explain` call raised `KeyError`. Also fixed:
  own drifted/incomplete feature list replaced with columns read directly
  from the fitted `ColumnTransformer`; `build_feature_set()` now receives
  `thresholds=` (was defaulting to zero, repeating the P0.2 skew bug);
  added `StackingEnsemble` compatibility.
- **`src/monitoring/drift.py` non-functional**: used Evidently's pre-0.5 API
  (`ColumnMapping`, `evidently.report.Report`), removed entirely in 0.7.x.
  Rewritten for the native `Report`/`Dataset`/`DataDefinition`/`presets` API.
- **Drift reference snapshot never generated**: nothing in the codebase ever
  wrote `data/processed/reference.parquet`, so `drift_monitoring_flow()`
  always failed with `FileNotFoundError` regardless of the API fix above.
  Added `save_reference_snapshot()` task, run at the end of every successful
  `full_pipeline_flow()` training run.
- **`AlertManager` missing `.send()`**: `src/monitoring/performance.py` called
  a generic `AlertManager().send(title=, body=)` method that didn't exist —
  only typed methods (`send_drift_alert`, etc.) were defined. Added.
- **`src/data/quality.py` schemas rejected valid partial data**: every
  `Column()` defaulted to `required=True`; any dataframe missing even one
  optional field failed validation entirely. Marked all non-key columns
  `required=False`.
- **Data quality contracts never wired in**: `quality.py` claimed to run
  "automatically in MultiSourcePipeline" but nothing called `validate_source()`
  anywhere. Wired in after each source load (non-strict — warns, doesn't crash).
- **Test suite not portable**: `test_feature_store.py` read
  `data/raw/client_data.csv` directly (gitignored, never generated by CI) —
  this test module has likely been failing in CI silently. Fixed to use
  `conftest.py`'s synthetic in-memory fixtures.
- **Coverage config hid the buggiest modules**: `pyproject.toml` excluded
  `src/monitoring/*` and `src/pipeline/*` from coverage — exactly the
  modules with the bugs above. Removed; honest figure is 67%, not the
  previously reported 92%.
- Dead code removed: `add_timing_header()` had ~20 unreachable lines after
  its `return`; `pipeline.py`'s `hasattr()` mutation branches could never
  execute (factories already construct correctly); `src/data/loader.py` was
  entirely unused; duplicate docstring in `full_pipeline_flow()`.
- `evidently` re-pinned `0.4.30` → `0.7.21` (old pin worked but was
  unmaintained with zero test coverage either way).
- `opentelemetry-api`/`sdk`/`exporter-otlp-proto-grpc` added to
  `requirements.txt` — previously absent, so the advertised tracing feature
  could never actually activate even with the env var set.
- `datetime.utcnow()` → `datetime.now(timezone.utc)` in `performance.py`.

### Added — Test coverage for previously-untested modules
- `tests/test_drift.py` (6 tests): real `Report.run()` calls, genuine drift

- `tests/test_alerts.py` (9 tests): Slack/email dispatch, generic `send()`.

- `tests/test_performance.py` (13 tests): rolling metrics, degradation alerts.
- `tests/test_e2e.py`: +2 tests exercising `/explain` and `/explain/batch`

- `tests/test_pipeline.py`: +1 integration test confirming quality
  validation actually fires through the real pipeline.

### Added — Feature engineering expansion (13 → 38 features)
- `FeatureThresholds` dataclass with `schema_hash()` for contract drift detection
- 7 new domains: tenure, consumption, price, margin, support, billing, cross-source
- New features: `renewal_urgency`, `contract_completion_pct`, `days_since_modification`,
  `cons_per_product`, `revenue_per_kwh`, `power_utilisation`, `forecast_vs_actual`,
  `price_peak_ratio`, `price_trend_var/fix`, `price_volatility`,
  `clv_proxy`, `margin_per_product`, `escalation_rate`, `ticket_rate_per_product`,
  `service_quality_deficit`, `payment_reliability`, `financial_distress_score`,
  `revenue_at_risk`, `nps_tenure_interaction`, source flags
- `_safe_div()` helper for all division operations

### Added — 7-algorithm model sweep + ensemble
- `src/models/algorithms.py`: ALGORITHM_REGISTRY with LR, RF, GBM, XGBoost, LightGBM, CatBoost, MLP

- `src/models/threshold.py`: F1/F2/business-cost/recall-at-precision threshold optimisation
- `src/models/feature_contract.py`: 67-feature registry, `validate_features()`, `feature_schema_hash()`
- `src/models/churn_model.py`: full sweep + optimise + stack + threshold + MLflow
